Main loop

Collect, train, control

The detail page has five phases. Only one thing is in focus at a time.

  1. 01

    Empty

    Pick players and a target count. Creating a run does not start games, so you do not spend API by accident.

  2. 02

    Collect

    Start from the detail page. Watch live, replay, or load a demo first.

  3. 03

    Harvest

    When trainable decisions are ready, export ChatML and create a LoRA task.

  4. 04

    Control

    Register the fine-tuned player and run again on the same deals.

  5. 05

    Verdict

    One sentence and a Δ. When the evidence is thin, the number reads lighter.

Workbench

Treat games as data

Players, decisions, corpus, and training sit on one experiment line—not four disconnected tools.

Run locally

Two terminals, ten minutes

Python 3.11+, Node 20.19+ / 22.12+, Poetry. Ollama optional.

Clone, then start backend and frontend 
git clone https://github.com/blueWhalei/ai-card-game-lab.git
cd ai-card-game-lab
copy .env.example .env

scripts\start-backend.bat
scripts\start-frontend.bat
