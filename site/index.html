以实验为主线的
本地 AI 卡牌研究台

观战模型怎么出牌，采集对局，做 LoRA 微调，再用同一副牌对照。不内置权重，密钥留在本机。

查看源码 快速开始

主路径

采集，训练，对照

详情页按进度分成五个阶段。同一时间只强调一件事。

  1. 01

    空实验

    选好选手与目标局数。创建不会自动开打，避免误耗 API。

  2. 02

    采集

    从详情页开始实验。可以观战、回放，也可以先加载演示局。

  3. 03

    收获

    可训练决策就绪后导出 ChatML，开一个 LoRA 任务。

  4. 04

    对照

    登记微调后的选手，用相同发牌再跑一轮。

  5. 05

    结论

    一句判断加一个 Δ。证据不够时，数字会显得更轻。

工作台

把对局看成数据

选手、决策、语料与训练在同一条实验线上，而不是四套互不相干的工具。

本地运行

两个终端，十分钟

需要 Python 3.11+、Node 20.19+ / 22.12+、Poetry。可选 Ollama。

克隆后分别启动后端与前端 
git clone https://github.com/blueWhalei/ai-card-game-lab.git
cd ai-card-game-lab
copy .env.example .env

scripts\start-backend.bat
scripts\start-frontend.bat
git clone https://github.com/blueWhalei/ai-card-game-lab.git
cd ai-card-game-lab
cp .env.example .env

./scripts/start-backend.sh
./scripts/start-frontend.sh

打开 localhost:5173。首页按「密钥 → 选手 → 实验」引导。无密钥可先加载演示对局。
