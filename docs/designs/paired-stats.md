# 固定席位的配对胜负

每个共同有效的发牌种子贡献一对二元结果。A 表示源运行，B 表示其对照。没有来源关系时，A 是第一列，B 是第二列。每局按冻结的观察对象计胜。见[主指标定义](../../specs/desktop-research-workspace/primary-outcomes.md)。

| A 的结果 | B 的结果 | 原始计数 |
| --- | --- | --- |
| 胜 | 胜 | both_won |
| 胜 | 负 | a_only_won |
| 负 | 胜 | b_only_won |
| 负 | 负 | both_lost |

例如，同一副牌在 A 局由地主获胜、在 B 局由农民获胜，研究全桌地主胜率时计入「仅 A 胜」。研究指定选手时，则分别按该选手在两局所属阵营的胜负填表。

四格之和为有效配对数 n。共同计划取各组计划种子的交集，未纳入数等于共同计划数减 n，包含待采集。每个未纳入种子只计一次，保留各运行的原因。审查表另按每组自己的计划统计；计划外和缺少种子的对局单列。没有有效配对时，四格计数为零，配对差值、p 值及区间为空。

## 检验与区间

配对胜率差 B − A 等于（仅 B 胜数 − 仅 A 胜数）/ n。双侧精确 McNemar 检验只使用两类不一致对数；有有效配对而没有不一致对时 p = 1。详情页若站在 A 的视角，则反转差值和区间两端，原始计数仍按标明的 A、B 身份展示。

令 pB、pA 分别是「仅 B 胜」和「仅 A 胜」的概率。在配对之间独立同分布的抽样模型下，这两个事件各有以 n 为分母的二项边际分布。分别反演二项分布获得 97.5% 的双侧 Clopper–Pearson 区间，每端尾概率为 0.0125。[NIST 二项精确限](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbici.htm)

本项目将两个区间组合成 [LB − UA, UB − LA]。Bonferroni 不等式使两个边际区间同时覆盖的概率至少为 95%，无需假设同一对中的两类事件独立。代价是差值区间偏宽；区间和 McNemar 检验回答相关问题，但并非同一检验的互逆结果。全组单项胜率仍各用 Wilson 区间。调试用牌经过选择或存在跨局依赖时，覆盖率的抽样解释受到限制。[NIST 同时置信区间](https://www.itl.nist.gov/div898/handbook/prc/section4/prc473.htm)

若全部 n 对都一致，差值为零，区间为 ±(1 − 0.0125^(1/n))。1 对一致时是 ±98.75 个百分点，20 对一致时约为 ±19.7 个百分点。同向差值恒为 +1 或 −1 也保留抽样不确定性。小样本测试覆盖四格计数、交换方向、解析端点及枚举三项分布计算的覆盖率。

## 调试和独立验证

公开固定基准、自由发牌以及复制的运行均作探索使用。确定 Prompt A/B 设计后，在变体 B 的「查看条件」中打开独立验证组。系统一次性复制双方冻结的选手、提示词、评估器、主指标、假设和局数，给 A′、B′ 分配相同的新发牌计划。种子位于独立于内置基准和自由抽取的范围，并排除本地已记录的计划和对局种子。两组在同一事务创建，重复打开复用同一对，创建不会启动采集。产品内复制验证运行会使用公开调试牌，追加配对对照需从原调试运行开始。导入实验包可复现所带牌组，其结果按探索用途解释。

验证只比较此设计的 A′ 与 B′。调试与验证不合并估计；验证运行与其他计划的混合比较标为探索性。验证计划尚有发牌未纳入时仅报告当前样本。独立指新牌相对于冻结设计和本地留存记录的隔离；查看结果后调整设计、反复挑选结果或在外部使用同一批牌，都会限制泛化解释。
