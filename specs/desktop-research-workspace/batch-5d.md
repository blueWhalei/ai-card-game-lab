# 第五批 D：导出后定位文件

日期：2026-11-05。落实第五批导出目录定位，关联 R8、R9、R10；沿用已批准的桌面系统能力边界和现有 JSON 导出流程。

## 验收条件

1. 当桌面 JSON 保存成功时，现有成功提示提供「在文件夹中显示」。提示保留至操作完成、手动关闭或本窗口下一次保存成功，便于键盘操作；同一窗口最多保留一个导出成功提示。
2. 当用户点击定位时，系统文件管理器显示本次已保存文件；不自动启动文件关联程序，不再次导出。取消和保存失败不生成定位入口，浏览器不显示原生操作。
3. 当文件被移动/删除、系统定位失败或原生操作正在进行时，提示定位失败并允许重试，仍保留保存成功的事实。等待期间禁用重复点击。
4. 页面仅持有宿主返回的保存记录编号；宿主按调用窗口校验编号并读取自己保存的路径，拒绝任意路径、其他窗口或已被下一次保存替换的记录。每个活动窗口只保存一条内存记录，窗口销毁时清理，不写历史记录到磁盘。
5. 受限定位命令与保存复用研究源检查和关闭协调器。只调用官方文件定位 API，不向前端授予 opener、shell 或通用文件权限。

## 实现与验证

- [x] 更新唯一保存命令返回值为记录编号或 null；增加窗口隔离的保存记录和受限定位命令，移除旧布尔返回约定，不保留兼容分支。
- [x] 为现有 Toast 增加可等待的操作，复用按钮样式、关闭入口和中英文文案；由唯一 JSON 导出入口接入。
- [x] 验证取消/错误、连续导出、跨窗口/失效编号、记录清理、重复点击、定位失败重试；完成原生保存与文件定位验收。
- [x] 同步使用说明、架构、实施计划及实际验收边界。

实际检查与原生验证见 [第五批 D 验收](validation-5d.md)。

本批不创建文件历史页、文件浏览器或新的导出内容服务。可读报告、窗口布局恢复、凭据管理及发布安装验收仍保留在原计划中。
