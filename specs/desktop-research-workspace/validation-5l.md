# 第五批 L 验收记录

2026-11-20。在研究内打开「任务与已记录用量 → 预算与费用 → 从费用 CSV 对账」。选择已有成功快照和逐日项目费用文件，按表头映射金额和 UTC 服务日期，再填写文件对应的组织、项目、币种、服务期间和筛选范围。

服务端逐行核对期间及已映射的范围字段，按十进制求和并保留负向调整。文件期间按 UTC 整日比较，终点不含。文件行不去重、不自动过滤或补齐缺失日期。未映射的组织、项目或币种取自用户填写的信息。文件摘要和行日期只能用来定位数据，费用覆盖范围与结算情况仍需核对来源。

本地浏览器使用合成文件和独立数据库。两行金额为 0.200000000000000001 USD 和 −0.000000000000000001 USD，服务日期均为 2026-11-18。对照快照该日的金额为 0.100000000000000000 USD。项目 ID 不符时拒绝预览。修正后预览及保存的差额为 **−0.100000000000000000 USD**，产生一条待复核记录。历史明细可查到列映射、日期、行数和文件摘要。SQLite 只读复核确认摘要与原文件字节一致，未保存原始行内容，原有人工登记仍为 0.100000 CNY，新增牌局为 0。浏览器未记录错误或警告。 浏览器截图（本地验收产物：`output/cost-csv-20261120/csv-reconciliation-zh.jpg`）

后端费用与预算回归 **66 项通过**，涵盖 UTF-8 BOM、引号与换行、18 位小数、文件字节变化、版本化保存、幂等、范围拒绝及校验失败时隐藏文件内容。Ruff 和 mypy 通过。前端费用组件回归 **32 项通过**，包含文件读取、列映射修改使预览失效、保存复用原文件及其他预算流程。前端 lint、类型检查和生产构建通过。
