# 第四批 E：正式报告引用局面测试

2026-11-08，延续已授权的 R4、R5、R6、R7、R8、R10。

## 验收行为

- 比较结论编辑器可浏览关联运行的测试集、分页选择历史结果，先查看来源与条件，再显式加入草稿并填写引用说明。刷新复用现有草稿服务；不自动运行测试或发布结论。
- 预览和发布共用同一来源核对：仅支持由单次决策建立、只含一个局面的测试集；v2 结果有效、测试集指纹及保存摘要一致，完整局面内容哈希与原始决策重建结果一致；所属运行、对局、发牌和决策时间均符合比较冻结的共同样本；保存评估参数与该决策一致。批量抽取及旧记录、当前来源变化/缺失、来源在范围外时拒绝引用，但仍可独立查阅。
- 草稿保存测试身份、内容哈希和说明。发布再次读取并比较预览哈希，变化时拒绝整个发布且保留草稿。重复引用拒绝，每版最多 5 条测试引用，冻结测试及决策内容总计最多 8 MiB。
- 结论版本保存完整测试结果、发布时的来源核对及决策字段。已有版本没有测试引用时保持原样；当前文件及来源状态在读取响应中单独提供，不改写版本。结果文件修改、删除、未知版本或损坏均不妨碍查阅已冻结内容。
- 可读报告和 HTML/JSON 导出包含“引用的局面测试”，明确为探索性诊断、不增加比较有效样本或证明总体优势。复用现有局面测试正文、报告导出和来源状态机制。
- 报告 → 当前测试 → 来源决策 → 原测试 → 原报告引用保留具体结论版本及引用位置，纳入桌面地址白名单。缺失结果不自动改选。

## 结构与界面

仍用 API → Service → Repository/Core。扩展现有比较草稿和 research_revisions JSON，不新建保存路径；PuzzleService 注入 ExperimentService，研究来源核对由服务函数集中完成。比较编辑器沿用 Ink Lab 侧面板、现有控件和折叠详情，不重新设计页面。报告新增一节并复用 PuzzleResultDocument；当前状态与发布时快照明确分开。

这是单决策测试引用与可读证据交付。局面估计不是金标准，输入顺序重复不是独立对局。批量抽取测试的正式引用、整组场景抽样、其他变体、完整牌桌联动及桌面发布继续留在后续任务。

## 检查

API 覆盖范围、来源变化、哈希冲突、去重/数量/体积、不可变版本、草稿恢复和只读不执行；前端覆盖选择/移除、错误、迟到响应、报告导出和精确返回。完整质量检查加隔离合成数据浏览器验收，不调用模型。
