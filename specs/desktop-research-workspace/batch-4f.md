# 第四批 F：批量抽取测试的正式引用

2026-11-08，延续已授权 R4、R5、R7、R8、R10。

- 沿用现有从运行抽取、测试历史、比较草稿与结论版本；不新建报告或保存路径。
- 新批量测试集保存抽取时已完成对局范围、成功生成估计的候选清单、阈值、按估计收益极差降序的排序规则、每局及总数上限、入选数量与逐局面来源核对。相同极差保持候选原顺序。成功候选不等于全部决策，缺失和评估失败可能造成选择偏差；这不是随机抽样。
- 批量抽取重新估计收益，明确区别于单决策测试复用原估计。报告保存实际评估参数与后续策略，不假定与原决策的估计相同，不将最高估计收益行动称作标准答案。
- 预览和发布核对全部入选局面的连续历史、完整观测与合法行动、原决策内容指纹、抽取摘要、选择规则及比较共同样本/截止时间。任何一条无法核对就拒绝整条测试引用，不自动删去不合格局面。旧测试缺少核对记录时仍可独立查阅，不补造来源。
- 每条引用最多 200 个局面，继续每版最多 5 条及 8 MiB；不增加有效对局/配对数，不作总体或因果推断。
- 正文以可读文字展示候选、入选、不同来源对局数及选择局限，保留逐局面来源链接和原报告返回位置；HTML/JSON 与页面同源。中英文、指南、API 和剩余清单同步。

核验：真实连续动作加合成估计的 API 测试，覆盖全部来源、数据变化、缺失、排序/阈值/上限、禁止发布时模拟、不可变版本与旧记录拒绝；前端与隔离浏览器检查批量正文、来源往返和实际导出。不得将软件验收当作研究效果证据。
