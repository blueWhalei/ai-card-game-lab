## 已完成

- 决策详情 → 查阅来源 → 填写测试问题 → 保存单个局面 → 离线基线/指定输入顺序扰动 → 来源决策 → 原测试集。
- 保存已有收益估计，不新增模拟或模型调用。校验连续且唯一的历史、发牌与席位、记录上下文、合法菜单、至少两个合法行动、候选收益和参数。兼容实际保存格式中省略的叫分 target，通过规范行动 ID 核对；显式保存的 target 仍必须一致。

- 测试集缺失不自动替换；旧详情或旧测试响应不覆盖新选择。来源决策继续浏览其他步骤后仍可返回原测试集，桌面地址白名单保留该关系。
- 文案使用「局面测试集」「估计收益」「探索性诊断」；将「菜单截断」改为「部分合法行动未评估」。未评估不算错误，个例及重复扰动不算独立验证。

## 边界与剩余工作

局面来自观察后的选择，不能推出整体策略优势、模型稳健性或因果结论。当前引擎回放可与记录核对，但不等于提供历史环境完整复现包。只有完整历史和评估数据的决策可用。

本批没有整组场景抽样、其他变体模板、模型调用、训练或独立留出实验。已有运行结果会保存到本地测试集目录；页面刷新仅恢复测试集，历史基线/扰动结果读取及纳入正式报告仍待实现。未改动 Rust 宿主或重建安装包，未提交或发布。
