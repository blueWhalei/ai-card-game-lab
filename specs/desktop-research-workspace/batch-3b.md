# 第三批 B：运行内场景、对局与决策导航

2026-11-07，执行已授权的 R4、R5、R10，沿用现有研究工作区。

## 可验收行为

- 从运行详情打开「场景记录」，按既有互斥分类浏览全部、叫地主、一般出牌、残局、炸弹/火箭记录。显示分类规则和阈值，不能把项目分类视为公认的能力维度。
- 每组提供决策记录数、涉及对局数和已评估记录数。决策数不作独立样本数；同一对局可出现在不同组，对局数不可跨组相加。缺少评估不是零差值；不对不同评估条件的估计进行汇总排名。
- 选择场景后按对局浏览，再查看该场景内的决策、动作、手牌和既有评估范围。对局与决策分别分页，稳定排序；保留未完成对局并显示状态，未记录决策的对局单列数量。
- 使用当前数据库中的记录并标明读取时间，不冒充冻结比较样本。炸弹组按实际动作选择，属于事后描述性分组，不能据此识别提示词的因果效应。
- 完整决策页提供返回原运行场景的入口；刷新、切换记录及桌面位置保存保留场景、对局、分页和原决策位置。过期响应不能覆盖新范围；明确显示缺失、无结果、错误和重试，不静默改选其他对局或决策。
- 完整决策页的顶部计数标明运行整体或全部已保存记录的统计范围，不将其当作已应用单局等列表筛选后的分母。明确指定的决策缺失或不属于当前对局时显示提示，不替换为列表首条。
- 删除被替代的训练格式差值条形图，复用同一分类规则、决策预览和完整决策工作区。无模型调用、不重评决策、不新增统计推断或正式结论。

## 设计与数据边界

界面延续 Ink Lab 编辑式布局、IBM Plex Sans / Noto Sans SC、背景 #f5f5f7、表面 #ffffff、正文 #1d1d1f、强调 #1a6b5c。复用运行详情侧面板，先列分类和计数，再按需展开对局/记录。窄窗口按单列排列，明确主次，不增加导航模块或另一套牌桌。

新增只读 `GET /experiments/{id}/scenarios`，支持 scenario、game_id、decision_id、game_page、page，分页固定每页 20 条。API → ExperimentService → scenario_service → DecisionRepository；一个读事务内完成归属检查、分组计数与分页。所有查询限制同一运行，复用 `core.stats.scenarios.SCENARIO_SQL`。分类不存在、跨运行对局或越界决策不得回退到其他记录。只返回预览所需字段，不复制完整提示词和推理文本。

地址 `experiments/:id?panel=scenarios&scenario=...&scenario_game=...&scenario_games_page=...&scenario_page=...&scenario_decision=...` 只定位阅读状态。完整决策页另带 `scenario_run` 保存返回所属运行，复用这些定位参数；不接受任意返回 URL。桌面恢复继续使用既有白名单机制。

本批只完成单运行的描述性场景导航。冻结比较中的场景差异下钻、正式引用扩展、完整牌桌联动与针对性测试设计仍待后续，不据本批检查声称模型改进。

## 验证

API 检查互斥分类优先级、分母、零评估、跨运行隔离、空运行、未完成对局、分页、删除与非法筛选。前端检查筛选与返回、分页、迟到响应、明确缺失和重试。运行质量检查并用隔离数据完成真实浏览器验收。
