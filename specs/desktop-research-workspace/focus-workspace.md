# 聚焦任务的运行与分析工作区

日期：2026-11-03。用户已审阅原型并授权实施。本规格描述正式 Vue 工作区；静态原型已删除，不维护第二套页面。

## 设计规则

主区域回答当前任务，条件、完整指标、历史与编辑器按需打开。首屏保留影响判断的样本量、区间与配置限制，不能为简洁隐藏证据不足。延续 Ink Lab 主题、字体与间距，浅色、深色和中英文共用一套结构。

| 场景 | 主区域 | 按需内容 |
| --- | --- | --- |
| 尚未开始 | 研究问题、计划人数/局数、启动阻碍或开始按钮 | 冻结条件、笔记；开始后确认本批数量和用量说明 |
| 正在运行 | 已完成进度、观战与取消采集 | 对局明细、暂停/继续、条件与运行记录 |
| 已有结果 | 结果判断及不确定性、审查决策或比较入口 | 选手表现、场景差异、基准报告与笔记 |
| 比较分析 | 双组差值、方向、有效样本与区间；保存后查看同源对局的共享记录时间线（双组斗地主）或选择单次决策 | 更换运行、协议/样本审查、完整指标、快照管理、观察草稿与已发布结论 |

更换运行或修改允许变化字段后，不继续显示旧结果的主判断及证据，要求重新比较。多组比较维持探索性表达，不套用双组主指标或作显著性排名。完整指标在小窗口仍可通过侧面板横向滚动访问。

## 证据与记录

保存比较仍调用原有服务重新计算并冻结统计和样本覆盖。候选决策与双组对照由研究 API 严格按冻结 `coverage.members` 返回；没有候选时显示缺失状态，不生成示例片段。

选择候选后，通过现有决策 API 读取实际动作和手牌，复用 CardDisplay 和动作翻译。请求序号防止快速切换时迟到响应覆盖当前选择；ID、对局、选手与轮次不匹配时拒绝展示。编号按需展开，详细上下文通过原有决策工作区查看。

观察、解释、局限与引用复用 SQLite 草稿和原有结论版本服务。关闭编辑面板不丢弃会话，刷新后从数据库恢复；保存草稿不等于发布正式结论。重复引用同一决策不会添加第二份。

## 工程边界

- 运行详情复用 useExperimentDetail；阶段动作的采集先打开既有确认流程，不直接发起请求。
- UiDialog 增加侧面板布局，复用 Reka 的语义与焦点约束；关闭后恢复仍存在的触发元素焦点。
- ComparisonOverview 仅展示后端统计结果，ComparisonDecision 读取单次决策，ComparisonReplay 管理共享记录时间线，两者复用 DecisionPreview；不新增统计、采集、持久化或协议兼容实现。
- ExperimentMetaPanel 仅负责条件展示，删除原有重复折叠/对话框分支；笔记由原组件单独承载。原有功能移入对应入口，不并存新旧工作区。

## 当前边界与后续工作

第三批 A 已接入同源对局选择、双方记录时间线、首次行动分歧与双侧引用；记录路径不足时明确标记，决策现场返回保留对局及步骤。此处不是隐藏状态重建或完整模型输入对齐。自动发现跨场景差异、统一牌桌分析和桌面窗口现场恢复仍属于后续工作。不能以卡牌预览证明推理过程或总体策略提升。
