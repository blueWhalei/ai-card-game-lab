# 第三批 F：调用记录正式引用

继续已授权 R4、R5、R7、R8、R10，复用既有研究、草稿、比较和报告实现。

- 从调用详情选择符合冻结共同样本的比较。候选发现、只读预览和发布均核对对局归属、发牌种子、席位及时间界限；不靠同一运行推测样本归属，不执行模型或补写记录。
- 预览保存的输入、输出、指标与子操作，说明它们是保存文本和运行诊断；子操作不是独立调用样本，也不等于完整供应商请求日志。创建时间截止不意味着内容在比较时已冻结。
- 以规范化 JSON 指纹核对预览内容，显式加入同一比较草稿，每版至多 5 条，每条内容至多 2 MiB，总计至多 8 MiB。内容变化拒绝发布，保留草稿；重新查阅后可明确更新已有引用的指纹，保留引用说明。
- 发布时在同一事务冻结调用正文、来源身份、指纹与说明。后续修改、删除、身份变化或不可读取分别提示，已发布正文不被覆盖，不能让坏的当前来源阻断旧报告读取。
- 可读报告与 HTML/JSON 导出包含冻结引用和解释局限；当前调用入口精确定位记录，过滤不匹配、记录不存在或读取失败不得改选其他记录。保留原报告引用及返回位置，复用桌面路由恢复白名单。
- 沿用 Ink Lab、现有选择对话框、引用按钮与报告结构；中英文、API、任务与验收同步。任意附件、跨模型模板、预算概览、独立用户和发布验收仍待完成。
