# 第二批 A：研究组织与继续工作

状态：已完成源码实现与本机验收，见 [验收记录](validation-2a.md)。范围对应 R9 与相关 R1、R7、R10。第二批拆成可独立验收的 A（研究组织）和 B（Prompt A/B 设计与启动条件）；本次交付 A，不将 B 标为完成。

## 用户流程与验收

首页选研究 → 阅读问题与已有运行 → 创建下一次运行或审查已有运行 → 比较 → 保存快照与正式结论 → 返回研究继续工作。

- 新首页以研究为主，提供最近活动排序、名称/问题搜索、选中预览和明确的继续入口。空状态引导创建研究，也可直接进入快速实验。
- 一个运行最多属于一个研究。快速创建运行时自动建立研究；复制与配对对照默认归入源研究。明确指定的研究不存在时拒绝创建，不能留下半条运行。
- 现有未组织运行可由用户明确加入研究；已属于其他研究的运行不得静默移动。不对已有数据库做猜测性批量归组。
- 研究显示运行与相关比较快照；只有比较包含的全部运行都属于该研究，才列入研究记录。跨研究比较仍可在比较库查看，不冒称某个研究的结果。
- 研究内创建运行复用唯一创建表单与服务。实验详情返回所属研究；所有运行库保留为检索工具，首页旧实验列表入口改为 `/experiments`，不保留首页路由别名。
- 加载失败展示可重试状态，不能伪装为空数据；切换研究不会显示前一研究的数据。

## 设计规格

目的：让用户围绕研究问题连续组织运行与证据，而不必记忆实验 ID。桌面 WebView 与浏览器共用 Vue 实现。

风格：编辑式研究工作室。首页为不等宽列表/预览双栏；研究详情以问题为标题，运行在主栏，研究记录在侧栏。小窗口按同样阅读顺序堆叠。

配色沿用实际 Ink Lab tokens：纸色 #F5F5F7、表面 #FFFFFF、墨色 #1D1D1F、次级文字 #48484D、强调绿 #1A6B5C。深色模式使用现有语义 tokens。字体 IBM Plex Sans / Noto Sans SC，保留平台字体回退；不引入另一套主题。Lucide 图标、可见焦点、真实空态，不放假指标或装饰性统计图。

## 实现边界

新增 `studies` 和 `study_runs` 关系表，运行 ID 是关系表主键；研究名称与问题独立于单次运行的假设。使用外键和事务，复用已有 ExperimentRepository 创建流程，在同一事务内完成自动组织。新增 StudyService/StudyRepository，研究仅负责组织，不实现另一套实验、统计、草稿或结论服务。

比较归属从冻结快照内的运行 ID 与当前组织关系推导，不复制快照、证据或正式结论。列表聚合由 SQL 完成；研究详情只请求所属运行的既有摘要。已有未组织运行仍是合法的可手动组织数据，不提供旧协议转换或双写路径。

接口：`GET/POST /api/v1/studies`、`GET /api/v1/studies/{id}`、`POST /api/v1/studies/{id}/runs`。创建实验增加 `study_id` 作为组织上下文；省略时自动建立研究。普通运行接口继续执行原有业务。

## 验证计划

API：自动归组、指定研究、复制/对照继承、缺失研究无残留、重复归组幂等与跨研究拒绝、比较记录范围、重启持久性。UI：搜索、选中、加载失败、继续入口、研究上下文创建。浏览器：创建研究和运行、返回研究、刷新恢复、对照与比较入口、窄屏与深色模式。

未参与开发用户的独立可用性验证仍需后续进行，自动化交互不替代该退出标准。桌面安装包重建与原生退出握手不在本单元范围。
