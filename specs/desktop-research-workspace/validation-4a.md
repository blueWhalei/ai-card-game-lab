# 第四批 A 验收：可读报告与引用导航

日期：2026-11-06。对应[批次设计](batch-4a.md)，对象为当前 Vue/FastAPI 与 Tauri 源码。

## 已交付

- 正式结论及历史版本都有「阅读报告」入口，地址绑定结论版本。页面、HTML 和 JSON 使用同次读取的冻结比较与引用；数据截止、结论保存和原记录状态核对时间分别标明。
- 正文包含研究假设、运行条件、分析单位、有效/排除样本、四格计数、差值方向、区间和方法说明。运行假设只在新比较中保存，旧快照缺失时不从当前运行补写。
- 明确独立同分布假设、Clopper–Pearson/Bonferroni 区间构造、精确 McNemar 检验与区间并非互逆、引用选择偏差及探索/留出解释范围；不把软件通过检查解释为模型能力或训练收益证据。
- 作者观察、解释、局限与冻结证据分区。未评估值不显示为零；来源修改、删除或身份变化不覆盖已保存引用。选手、动作与牌面有可读显示，保留原始编号核对。
- 引用可进入当前决策或冻结比较所指的对局步骤，继续看其他决策后仍返回原版本的同一引用。来源只解析冻结共同成员；缺失或歧义不猜测发牌。
- 独立 HTML 保留页内目录、展开明细、内置阅读/打印样式，无脚本和外部资源；应用内跳转不混入离线文件。JSON 保留机器可读字段。桌面共用固定 JSON/HTML 格式、32 MiB 限制、原生保存与关闭互斥。
- 修正新生成演示记录的轮次为从 0 开始，与正式配对时间线一致；不改写已存在的历史演示数据。
