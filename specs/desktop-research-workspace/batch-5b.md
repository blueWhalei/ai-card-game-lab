# 第五批 B：关闭后继续上次研究

日期：2026-11-05。落实 R4、R9、R10，承接第五批 A 的正常关闭握手。本批交付主窗口研究位置恢复，不新增常驻界面区域。

## 验收条件

1. 正常关闭主窗口时，除草稿外还须确认研究位置已保存；再次启动在当前后端源恢复该位置，不保留上次随机端口。
2. 支持研究首页、研究详情、运行列表/详情、比较和决策审查。只保留各路由声明的定位参数；比较快照、样本、时间线与决策返回上下文复用现有 URL。
3. 进入设置、向导等非恢复页面时保留最后的研究位置；主动回研究首页则下次仍从首页开始。恢复不打开未提交创建表单，不自动运行实验或调用模型。
4. 只有主窗口读取/保存恢复记录，证据窗口不能覆盖主窗口现场；浏览器入口不调用原生能力，显式打开的页面不被启动恢复覆盖。
5. 记录缺失时正常进入首页；损坏、过大或非法记录提示恢复失败并允许继续工作。写入失败取消关闭，研究草稿不被丢弃。
6. 取消关闭后继续导航，下一次关闭必须保存新的位置；最终保存成功之前不能停止服务。

## 设计与范围

- Vue 路由元数据声明可恢复的查询键，唯一规范化函数筛选定位参数；不为旧地址、未知参数或历史记录结构增加转换。
- 主窗口启动时在挂载编辑器前读取恢复记录。导航只更新内存中的最后研究位置，关闭准备阶段通过现有生命周期入口提交；这不是强制结束/断电保护，也不是每次导航落盘。
- Rust 在应用数据目录固定的 `workspace.json` 中保存相对路由；临时文件写入并同步后替换正式记录。命令限定主窗口与精确后端源，不接受文件路径，不暴露通用文件系统权限。
- 草稿继续使用 SQLite 草稿服务。页面数据、比较快照及决策读取沿用现有 API，记录本身不复制业务对象；对象被删除时由原页面显示读取失败，用户可返回研究首页。
- 证据窗口集合、窗口尺寸/屏幕位置、滚动位置、临时面板、未提交向导、快捷键与凭据管理仍在后续计划。
