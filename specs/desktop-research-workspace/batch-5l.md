# 第五批 L：项目费用 CSV 对账

在研究的「预算与费用」中选择成功快照，读取本地 UTF-8 项目费用 CSV，将日期和金额列映射到对账字段。官方导出说明区分 Cost data 和 Activity data。实现接受符合约束的逐日项目费用 CSV，并由用户确认组织、项目、币种、UTC 服务期间及导出筛选条件。 [OpenAI 费用导出说明](https://help.openai.com/en/articles/20001072-exporting-monthly-usage-details-from-the-api-usage-dashboard)

- 读取表头时返回列名，不创建对账。金额和服务日期列必选，组织、项目和币种列可选。已映射的范围字段逐行检查，未映射的字段采用用户声明。拒绝空文件、超出限额、畸形行、重复列名、无效金额、区间外日期或范围混杂。可用 UTF-8 BOM 文件及带引号的 CSV。
- 服务端按全部有效数据行精确求和，保留负向调整。区间起点含、终点不含，限已结束的 UTC 整日。文件不自动筛行、填补缺失日期或去重。预览展示 CSV 合计、范围和与快照的差额或不可比原因。
- 复用预览指纹、显式保存、复核与预算检查。保存时用同一份文件重新解析核对，记录文件名、原始字节的 SHA-256、解析版本、列映射、数据行数和首末服务日期。CSV 原文由用户保管。字节摘要用于复核所用文件，无法验证签发者、文件完整计费覆盖或结算状态。
- 保持原人工录入接口及历史记录可读。导入不新增人工费用、不发起供应商同步。对账金额不能作为完整研究费用。正式发票 PDF/Excel 文件、实际组织账单验收及支出硬上限仍待交付。
