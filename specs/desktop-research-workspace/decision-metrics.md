# 决策记录的解释范围

| 观察对象 | 记录 | 可以回答的问题 |
| --- | --- | --- |
| 一局中一个席位 | 终局阵营胜、负，或未知 | 该选手所在阵营是否获胜？同一局中该席位的多条决策共享这一标签。 |
| 一次决策 | 估计期望收益差和本次评估条件 | 在已评估的候选中，所选动作与最高模拟平均收益相差多少？ |
| 一次运行 | 有效解析数、训练格式可用数及其分母 | 哪些记录可用于复查或训练？ |

斗地主的决策工具读取当前选手的手牌，返回牌型特征和启发式评分。公开余牌数及手牌来自引擎观察。记录保留主观人工标注的来源。

斗地主当前决策协议版本为 3。采集和启动实验对局时核对冻结的决策协议版本，设计向导也会检查基线。跨版本研究可重新建立运行。

## 估计期望收益差

评估器根据决策时可见信息采样隐藏牌面。每个候选动作复用相同的牌面和续局随机流，由实际生效的基线策略完成模拟。差值取已评估候选中的最大平均收益减所选动作的平均收益，单位为引擎终局收益。候选有上限，所选动作总在候选中。零表示在本次候选和采样条件下并列最高；仅评估一个候选时，差值按定义为零。评估关闭、失败或缺少记录时显示未评估。

决策详情和回放读取随该步保存的候选数、合法动作数、隐藏牌面数、每牌面每动作模拟次数和实际续局策略。完整评估记录还包含步数上限、随机种子和候选收益。采样条件缺失的项显示为空。逐步结果的解释限于这些条件，尤其是截断候选及使用代理策略的情况。

## 运行诊断

实验比较把解析成功率和训练格式可用率归入运行诊断，按各自分母显示。场景诊断按决策条数计，结论草稿使用冻结的主指标和配对对局证据。SFT 可按席位终局结果、训练格式和估计期望收益差分别筛选。

## 2026-11-06 研究有效性修正批次

本批执行已审查的评分、偏好数据和术语修正，复用现有服务与页面。

- 当局面测试选择未评估动作时，收益差及最高收益动作判定为空；汇总只使用已评估选择，必须展示有效分母及未评估数。并列最高按保存的收益值判断，不按唯一动作 ID 判断。报告保存计算版本，已有报告不追溯改写。
- 扰动测试为每次扰动增加同随机流的未扰动对照，同时记录独立重复的动作一致率。该指标只描述给定输入变换和策略下的动作选择，不等于整体鲁棒性或决策正确率。
- 蒸馏导出复用记录时间线校验；只有从第 0 步连续验证至首次行动分歧的同源对局才能产生偏好对。缺失、重复、上下文不一致、后续路径分歧及非法动作须排除并报告原因。教师选择是偏好来源，不作为客观最优标签。
- SFT 验证划分按游戏类型与发牌种子分组；没有种子的记录按对局分组。同源发牌不能跨训练与验证集合。导出保存分组方法、数量和验证组成员；比例按组解释。
- 中英文统一说明估计期望收益差、最高估计收益候选、启发式评分及描述性模型胜率。移除“让出值”“战术分”和未经验证的样本效率提升承诺。置信区间、样本量提醒不得包装为功效计算。

验收覆盖未知动作、并列收益、空样本、随机策略无扰动对照、路径分歧后局部重合、非法教师动作、重复发牌与同源发牌隔离。前端验证空值、分母和中英文说明；后端检查单元、服务与 API 数据流。

## 前一批离线验收

在隔离数据目录使用打包后端运行固定首选策略的一局基准牌，共记录并评估 50 条决策。浏览器从决策链接打开其中一步，回放和决策记录均显示 3 个合法动作中评估了 2 个，使用 1 个隐藏牌面、每动作 1 次模拟，续局策略为 `first`。该步估计期望收益差为 0；第三个动作没有参与比较。打开同一运行与空运行的比较，运行诊断分别显示实际分母和缺失值。


## 研究术语约束

“估计期望收益差”在本项目中指保存的蒙特卡洛续局均值之差，是对具体计算量的描述，不是新的通用评价指标。斗地主当前终局收益按阵营胜负取 0/1，因此该差值不包含倍数或筹码得分。候选筛选与取最大值可能引入选择偏差；没有为单步差值提供置信区间，不能把很小的正差直接解释为可靠优势。

局面测试的最高估计收益选择比例和动作一致率都必须附带条件与分母。局面从较大候选收益极差的记录中筛选，不能据此推断全部决策表现。模型汇总胜率混合不同角色、对手和提示设置，同局队友结果相关；它是描述性结果，不是受控模型排行榜。

局面报告版本区分计算口径；教师偏好、模拟偏好、人工标注分别注明来源。启发式手牌评分属于人工规则，未经校准不能称为胜率或经过验证的能力量表。API 字段 `low_power` 仅沿用内部标识，实际含义是样本量或区间宽度提醒。

方法依据：配对二元结果使用[精确 McNemar 检验](https://www.statsmodels.org/stable/generated/statsmodels.stats.contingency_tables.mcnemar.html)，[置信区间解释](https://www.itl.nist.gov/div898/handbook/prc/section1/prc14.htm)遵循重复抽样覆盖率；同源数据划分参照[按组隔离的验证原则](https://scikit-learn.org/stable/modules/cross_validation.html#cross-validation-iterators-for-grouped-data)。这些依据不构成对当前数据质量、教师优劣或训练增益的验证。

- 后端完整测试：732 passed、2 skipped，`--cov=app` 覆盖率 86.74%，通过 80% 门槛。Ruff 检查/格式检查及 `mypy app/core app/services` 均通过。
- 前端：46 个测试文件、179 个测试通过；`lint:ci`、包含测试的类型检查及生产构建通过。使用本机 Node 24.14.0，未切换系统默认版本。
- 浏览器：生产构建与隔离后端，在 `output/research-validity-20261106/browser-data` 下使用合成局面。固定首选策略对两题集合得到已评估 1/2、未评估 1；并列题记为最高估计收益、差值 0，未知题保持空值。单个未知题显示有效 0/1；空集合 run/probe 显示空值及 0/0。中英文均核对解释范围。扰动结果显示各自有效分母及原输入重复一致率。
- 数据流：API 用例确认蒸馏只导出首个验证分歧，后续路径排除、冻结协议不一致返回 400；数据集登记用例确认同源发牌未跨文件、分组元数据持久化。专项用例覆盖重复种子、记录缺口、非法动作及未评估选择。

本批未调用真实模型，未执行微调，未重新生成桌面安装包。已有历史报告和数据文件保留原始内容；新导出使用新的校验及划分规则。原有 11 项未完成主任务保持未完成，下一开发顺序为可读报告、分析与证据导航、桌面任务/预算与发布验收；独立用户试用仍需实际参与者。
