# 第五批 F：研究内对局任务与已记录用量

落实已授权 R3、R5、R9、R10。按现有规格与 Ink Lab 侧面板直接实施，不建立另一套任务调度或费用估算系统。

## 范围与验收

- 从研究工作区按需打开“对局任务与用量”，按运行分页并筛选全部、有活动任务、有异常记录。状态只来自当前保存的对局；待启动不宣称已经进入调度队列，完成不等于共同有效研究样本。
- 同一只读事务核对研究归属，读取运行、状态计数及调用记录中的 token 字段。每页 20 个运行，全部筛选先于分页；未知状态单独计数，无结果与读取失败明确区分。
- 每个 token 字段独立报告有效非负整数字段的合计、有效记录数、缺失数和无效数；零是有效值，缺失不是零。输入、输出与总数字段不互相补算，不叠加 trace 与子操作或 round 中的重复数据；安全整数范围外的合计显示不可用。
- 注明当前保存记录及读取时间，无时间窗口，包含未完成对局。记录可能遗漏调用、重试或供应商用量；不代表完整账单、费用、预算余额或独立样本。预算上限和费用记录仍待实现。
- 异常计数提供打开原运行的入口和明确处理说明。失败/中断不可无损续跑；不自动重试、启动对局或调用模型。停止、连接检查和新采集继续使用原运行的流程。
- 面板筛选与页码由研究 URL 保存，去往运行可返回原任务位置；复用桌面位置白名单。刷新、关闭、切换研究时不显示旧范围或接受迟到响应。

## 界面与工程

目的：定位哪些运行仍有对局活动、哪些需要检查，并核对已记录用量的完整性。沿用已采用的 Ink Lab：语义色 `ink-primary/text/surface/border`、IBM Plex Sans 与 Noto Sans SC、六级文字 token；复用研究操作区按钮、右侧 UiDialog、列表分隔和 UiPagination。信息顺序为来源说明、筛选与刷新、读取时间、运行状态及用量、原运行入口；窄屏自然换行，不新增仪表盘或结果评分。

`GET /studies/{id}/operations?state=all|active|attention&page=1` → StudyService → 专用只读仓库；聚合先按运行分开，不用多表联接造成计数相乘。现有 studies、study_runs、experiments、games、traces 足够，无新表。返回带研究 ID、筛选、页码、总条数和读取时间的类型化前端响应。
