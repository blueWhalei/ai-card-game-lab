# 第五批 E：恢复主窗口布局

日期：2026-11-05。落实第五批窗口布局恢复中的主窗口部分，关联 R6、R9、R10。沿用持续实施授权，复用唯一工作区记录与关闭握手。

## 验收条件

1. 当主窗口正常关闭准备保存研究位置时，宿主同时读取普通窗口矩形与最大化状态，在同一 `workspace.json` 中原子写入；读取/写入失败沿用现有提示和关闭保护。
2. 当启动恢复工作区时，主窗口先恢复布局，再进入已保存的研究地址。最大化退出后再次打开保持最大化，恢复普通窗口时使用原来的普通矩形。最小化不作为启动显示状态。
3. 当保存的窗口位置完全落在当前屏幕之外时，使用 Windows 的窗口布局恢复机制将其调整到可见位置；不自己维护屏幕坐标到工作区坐标的转换。
4. 页面仅提交相对研究路由，窗口布局来自宿主自己的主窗口；证据窗口和普通浏览器不获得新的系统权限。
5. 工作区记录只接受完整的当前结构，字段缺失、未知字段和非法矩形明确拒绝，不增加默认字段补齐、格式升级、双写或第二套偏好存储。恢复失败后仍可使用应用，下次成功关闭写入当前记录。

## 技术实现

`workspace.rs` 保留记录读写所有权，增加布局字段；`window_layout.rs` 仅提供 Windows 布局采集/恢复与纯结构校验。复用现有 `windows-sys` 的 GetWindowPlacement / SetWindowPlacement，完整使用其工作区坐标，避免与 Tauri 屏幕坐标混用。初始化仍由主窗口 `read_workspace` 调用触发，显式地址刷新不重新调整窗口。
