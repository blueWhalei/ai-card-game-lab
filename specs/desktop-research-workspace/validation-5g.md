# 第五批 G 验收：研究内训练任务概览

日期：2026-11-19。范围见[设计](batch-5g.md)。

## 交付

- 研究工作区统一使用「任务与已记录用量」，按需切换对局与训练。训练任务每页 20 条，全部、活动、异常条件在分页前执行；未知状态计入异常，取消不计为失败。
- 训练任务归属仅依据保存的运行 ID 及当前研究—运行关系。复用训练列表 API，研究、运行、任务 ID 和状态联合过滤，在同一只读事务核对研究并读取总数和记录；响应附读取时间和实际过滤条件。未关联任务不按数据集来源推断归属。
- 已保存执行进度仅接受有限的 0–1 数字，缺失、无效和有效零分别处理，不根据完成状态补成 100%。配置与结果的损坏 JSON、非对象以及非有限数字明确标为无效，错误原因仅呈现已保存文本。
- 指定任务可从研究分页准确打开；任务不存在、过滤不匹配、读取失败与尚在加载分别展示，不替换为其他任务。返回研究保留任务类型、状态和页码；桌面地址恢复白名单同步。清除训练范围同时清除研究、任务及返回定位条件。
- 从运行范围创建训练任务时保留运行归属；创建后按当前范围刷新。任务读取不等待环境检查，避免首次加载暂时误报任务不存在。迟到请求与范围不符的响应不能覆盖当前列表。
- 取消和删除仍使用现有显式确认；概览只读，无自动启动或重试。中英文说明进度不代表剩余时间或模型质量，完成状态不能证明策略改进，未记录完整资源用量、费用或预算余额。
