# 第四批 A：可读报告与引用导航

本批依据已授权的 R4、R5、R7、R8、R10 实施，不改变统计计算或结论发布机制。

## 验收行为

- 打开正式结论版本时，可进入独立报告地址；刷新后仍读取同一版本和比较快照，不混入最新实验统计或未发布草稿。
- 报告包含冻结研究假设（缺失时明确说明）、运行条件、指标定义、分析单位、样本纳入/排除、差值方向、已有区间与检验方法、作者观察/解释/局限及逐条冻结证据。
- 配对对局数与引用决策数分别显示；未评估值、缺失数据、区间跨零、探索/留出用途、协议差异均不转化为强结论。报告不生成因果结论或保证训练增益。
- 引用有稳定序号与页内位置。能打开当前原始决策，并返回报告的同一引用；能返回冻结比较的发牌与步骤。原记录缺失或身份变化时禁用原记录入口，仍显示冻结证据。内容变化时明确告知。
- 同一报告组件提供屏幕阅读与独立 HTML 导出，HTML 离线可读、可打印，有页内导航，无脚本和外部资源依赖；保留原 JSON 导出。应用内链接不写成可移植的离线链接。
- 中英文一致，文本按普通文本呈现，恶意 HTML 不得执行。加载失败可重试，切换版本的迟到请求不能覆盖当前报告。

## 界面设计

沿用已批准 Ink Lab 编辑式信息层级：IBM Plex Sans / Noto Sans SC，背景 #f5f5f7、表面 #ffffff、正文 #1d1d1f、强调 #1a6b5c，实际页面使用既有主题 tokens。报告正文位于主区域，窄目录提供章节和引用定位，窄屏改为上方换行目录；不新增仪表盘或主题。静态 HTML 使用同一正文与独立阅读/打印样式。

## 实现边界

- `ResearchMixin.get_research(export=True)` 继续提供唯一报告数据源；新比较保存运行假设，旧快照缺失时不从当前运行补齐。
- `/research-reports/:id` 按结论版本定位，`evidence` 参数保存引用决策 ID。引用所属运行和发牌仅由冻结 `coverage.members` 确定。
- 当前决策与比较路由携带 `report_id/evidence`；即使继续浏览其他步骤，返回时仍定位原引用。演示生成器使用与正式记录一致的从 0 开始轮次，避免示例导航越界；不修改已存在的历史演示记录。
- 共用导出传输支持 JSON 和 HTML 两种固定格式；桌面继续只接受文件名/内容，限制 32 MiB，复用系统另存为、原子替换、窗口归属及关闭互斥。不存在任意路径或脚本执行接口。
- 不新增统计计算、不重写历史报告、不生成完整可运行复现环境。本批导航覆盖正式报告与已引用决策，完整场景下钻和任意证据引用仍保留后续任务。

## 检查

后端检查冻结假设和数据来源不漂移；前端覆盖空值、方向、缺失/变更证据、版本切换、返回定位及 HTML 转义；桌面检查固定格式/扩展名/大小/保存失败与既有互斥。运行项目质量检查，并使用隔离数据完成浏览器阅读、导航和离线 HTML 验证。

方法依据沿用[配对统计定义](../../docs/designs/paired-stats.md)。本批复核了 [NIST 精确二项区间](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbici.htm)与 [Bonferroni 不等式](https://www.itl.nist.gov/div898/handbook/prc/section4/prc473.htm)的适用解释；项目差值区间的组合规则在报告中明确写出，不将区间和 McNemar 检验视为互逆。
