# 斗地主席位胜负

一局有三个席位。地主先出完，两名农民均负；任一农民先出完，两名农民均胜。游戏记录中的 `winner_id` 定位先出完牌者，可用于回放。对局所属阵营由终局角色确定。规则见[项目玩法说明](../../docs/欢乐斗地主经典玩法规则.md)。

| 输出 | 计算口径 |
| --- | --- |
| 选手阵营胜率 | 在可判定该席位阵营胜负的对局中，以其阵营获胜局数除以有效局数；无有效局时胜率和区间均为空。 |
| 配对胜场 | 在比较的共同有效发牌上按阵营数胜场。若其中有无法归属席位的记录，则席位配对胜场为空。 |
| 按模型统计 | 一局中的一个席位贡献一次结果。只纳入有回合记录且所有回合均归属于同一模型名的席位；同一模型占两个席位时计两次。 |
| 地主阵营胜率差 | 对共同有效发牌比较地主阵营的胜负变化。该指标描述全桌结果，不能据此归因于指定选手。 |

数据库视图 `game_seat_results` 按正常结束状态、三个不同席位、地主身份和先出完牌者的阵营一致性确定席位结果。未决、流局和身份矛盾的记录不给任何席位计胜负。正常终局在同一事务里保存游戏结果与决策标签，演示数据走同一写入路径。两名农民共同获胜时，三名选手胜场合计为二。

本次修改对应比较口径 `paired-cohort-v3`。新比较按当前记录重新计算；已冻结的比较、结论以及已写入的历史决策标签不作追溯改写。需要按本口径评估训练样本时，应使用本批之后结束并已标注的对局。

验收用同一组终局分别令地主及两名农民先出完，逐席核对实际引擎回报、数据库决策标签和模型胜场。流局不产生有胜负的样本。模型占多个席位、每席多条回合时，按席位计数。见[回归测试](../../server/tests/test_services/test_seat_results.py)。
