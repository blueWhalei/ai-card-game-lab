# 第五批 I：供应商费用同步与独立预算限制

延续已授权开发，按官方费用接口可用性先实现 OpenAI Costs API。复用「预算与费用」表单与证据列表，不改变模型调用配置。

## 口径与验收条件

- 使用独立服务端 Admin API key 和组织 ID，只向官方固定地址读取费用；不向浏览器返回凭据、不将模型 API key、账户余额或 Token 用量当作账单。
- 用户明确选择供应商项目、UTC 起始日期、USD 上限、最长同步间隔（1–24 小时）。每次同步覆盖该起点到请求时刻，最长 366 天；区间含起点、不含终点，不自动重置预算周期。
- 费用属于供应商组织和项目范围，可能包含其他研究；项目以外、组织层级费用、其他供应商及未入账费用不在查询覆盖范围。API 返回费用并非最终结算发票，空结果和零值不能证明实际支出为零。
- 分页全部验证后原子保存新的快照和来源明细；重复同步替换当前快照，不累加历史快照。失败保留历史成功快照并标明失败；保存配置的新版本不能沿用旧版本快照。
- 按供应商项目费用单独限制受控任务，不与人工登记合计相加、不换算币种、不自动分摊至研究。任一已启用限制触发即拒绝新任务。供应商限制启用时，无有效快照、最后同步失败或同步间隔超限均拒绝新任务。
- 两类限制均不预留未来费用，也不中断已接受任务；供应商延迟和并行调用仍可能超限，不能称为实际支出硬上限。
- 配置版本、同步尝试、查询范围、失败类别和成功明细可追溯。并发保存使用版本条件；并发同步使用持久化占用记录，网络等待不持有数据库写锁。
- 中英文页面明确来源、时间、币种、覆盖范围、人工费用与供应商费用区别；失败保留输入，离开保护复用现有流程。
