## 浏览器验收

使用 Playwright CLI 验证：

1. 空首页创建中文研究及问题，进入研究工作区。
2. 从研究进入唯一运行表单，研究问题预填为假设；创建离线基线运行后，详情提供返回所属研究。
3. 明确确认运行，完成一局 first / heuristic / random 基线对局，无模型调用；返回研究可见完成状态。
4. 通过既有复制 API 生成第二次运行，刷新研究后显示同一归属；选择两次运行进入比较。第二次运行未执行，页面明确提示样本和协议限制。
5. 在浏览器保存比较快照，返回研究可见记录；显示“尚未发布正式结论”，重新打开可恢复快照与结论编辑入口。
6. 研究范围的运行列表切换到“全部运行”后清除研究上下文；刷新首页仍显示研究及两次运行。
7. 检查深色首页、浅色工作区和 390px 窄屏工作区。窄屏页面宽度与内容宽度均为 390px，没有横向溢出；研究记录按阅读顺序下移。
8. 原有“加载演示实验”入口移动到运行库后，仍能进入演示实验的结论阶段。

本地截图位于 `output/playwright/research-home-dark.png`、`research-workspace-light.png`、`research-workspace-narrow.png`，不纳入 Git。正常交互未观察到浏览器警告或错误，仅有开发工具日志。
