# 聚焦任务原型验收

日期：2026-11-03。本记录仅对应原型阶段。用户审阅后，正式 Vue 页面已接入，静态原型已删除；当前结构见 [工作区设计](focus-workspace.md)，正式功能检查见 [实施验收](validation-focus-implementation.md)。下列原型操作不代表真实业务能力。

## 已检查

通过本地 HTTP 服务与 Playwright 操作 Chromium，覆盖 1440 × 1000 和 390 × 844 窗口。

| 场景 | 结果 |
| --- | --- |
| 尚未开始、正在运行、已有结果 | 状态切换后主内容与动作同步变化 |
| 模拟开始 | 先打开确认面板，确认后才进入运行状态 |
| 暂停与恢复 | 页面状态与主标题同步更新 |
| 未完成时进入比较 | 显示等待证据，不展示已完成的配对结果 |
| 完成后进入比较 | 显示配对数量、差值、跨零区间及不能下结论的说明 |
| 片段与步数 | 切换片段同步更新 A/B；前后步更新共同回合标记 |
| 观察记录 | 输入后加入会话记录，导航计数更新，重开可见 |
| 键盘操作 | Escape 关闭检查器并恢复触发按钮焦点；Tab 留在打开的对话框中 |
| 窄窗口 | 三种运行状态与比较页面无横向溢出，记录面板可操作 |
| 减少动态效果 | 在 reduced-motion 设置下完成窄屏交互检查 |
| 页面脚本 | 最终刷新及状态导航未捕获 pageerror |

已人工查看桌面比较与窄屏比较、记录面板截图。布局允许纵向滚动，不以强行压入一屏为目标。

静态检查包括 JavaScript 语法检查和原型文件的 Prettier 格式检查。本次没有修改正式业务代码，未重跑前后端完整测试，也没有重建安装包。
