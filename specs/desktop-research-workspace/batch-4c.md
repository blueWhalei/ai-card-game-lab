# 第四批 C：从决策证据建立针对性局面测试

2026-11-08，落实已授权的 R2、R4、R5、R9、R10。

## 验收行为

- 场景、比较或报告下钻到决策后，可在决策详情填写测试问题，保存一个局面的测试集，再使用已有离线基线与输入顺序扰动测试。
- 只接受至少有两个合法行动且位于已结束运行对局中的可核对决策：连续行动记录、唯一决策、发牌种子、席位、手牌、公开上下文和完整合法行动菜单必须与当前引擎回放一致。缺失、歧义、解析回退或不一致应明确拒绝，不补写缺失状态。
- 复用原决策保存的行动收益估计和评估参数，不重新模拟、不调用模型。估计缺失、非有限值、非法候选或参考行动不一致均拒绝。保存前再次核对来源指纹，来源变化要求重新查阅。
- 测试集保存问题、运行/对局/决策标识、记录时间、读取时间、评估参数和来源指纹；可返回原决策。后续删除或修改数据库记录不改变已保存局面。
- 文案明确为事后选取个例的探索性诊断。最高估计收益行动不是标准答案，未评估行动不视为错误，可单独选择合法行动顺序或手牌顺序，也可共同置换；组合扰动不分别归因。重复扰动不增加独立局面数；顺序敏感性不等于模型正确性或整体稳健性。
- 不自动运行测试。显式指定的测试集缺失时不替换为其他测试集；切换测试集后的迟到请求不得显示到新测试集。

## 实现与界面

API → PuzzleService → 既有 Repository / Core。使用既有 puzzle pack 格式与 run/probe 计算实现，在 extract 元数据中保存来源，不增加数据库表或平行评分逻辑。GET 查阅可用来源，POST 携带查阅指纹及新问题保存一个局面。来源验证使用同一数据库读事务；保存的是该次读取快照，不承诺保存之后数据库仍不变。

决策详情增加次要操作和按需展开的对话框，沿用 Ink Lab 字体、间距、颜色与现有输入组件。测试页显示问题、来源链接、参数和解释边界，窄窗口自然换行。输入仅用于本次保存，未保存问题不宣称已持久化。桌面仅恢复测试集地址，不恢复提交触发器。

本批限于单个已评估、可回放决策。整组场景抽样、其他变体模板、模型测试和独立留出验证仍留在清单中。

## 检查

覆盖真实引擎回放、来源变更/删除、缺失估计、重复/缺失历史记录、非法估计、冻结后独立读取、前端中英文、迟到请求和明确缺失状态。执行前后端质量检查及隔离浏览器验收，不接触用户研究数据。
