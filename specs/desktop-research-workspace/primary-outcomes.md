# Prompt A/B 的观察对象与主指标

创建 B 时，研究者写下假设，并选择一个主指标。A 和 B 使用同一发牌计划和固定选手顺序。分析单位为一个共同有效的发牌种子，每组各有一局。

| 研究问题 | 每局如何计分 |
| --- | --- |
| 更换提示词后，指定席位所在阵营的胜率如何变化？ | 按该选手在当局的实际角色计分。其阵营获胜记 1，失利记 0。农民同伴先出完也记胜。 |
| 更换提示词后，全桌地主胜率如何变化？ | 谁担任地主均可。地主阵营获胜记 1，农民阵营获胜记 0。 |

该阶段共用一份提示词。受变更影响的席位由基线冻结的模型策略决定，包括 llm、tool_loop 和 search。这里记录按设计会使用新提示词的席位，不能据此推断每一局都发生了模型调用。离线策略不在清单内。指定选手从清单中选取；多个席位共同变更时，只解释共同变更下该选手的胜负。如需识别单席位变更的效果，可选择只有该席位使用模型的基线。

每个种子先算 B 的结果减 A 的结果，再取平均。指定席位的分析要求两侧均可从完整角色记录判定阵营胜负。缺失一侧就排除整对，并在覆盖审查中标明。比较矩阵、检验、差值区间和证据引用使用同一共同样本。详情从当前运行视角展示差值。与其他运行的自由比较使用全桌地主胜率。

## 如何核对

回归用例固定三名选手。A 由指定农民的队友先出完，B 由地主先出完。在角色齐全的同一发牌上，全桌地主的 B − A 为 +1，指定农民所在阵营的 B − A 为 −1。另一组发牌记录了获胜阵营，但 B 缺少地主身份，因此可以统计全桌地主胜负，无法归属到指定席位。当两侧各自都有可判定胜负的局、却没有共同可用的种子时，设计主指标差值为空。

- 在 `server` 目录运行 `python -m pytest tests/test_api/test_prompt_design.py`，覆盖两种主指标、样本排除、双向详情、冻结快照和报告导出。
- 在 `web` 目录运行 `npm run test:e2e -- e2e/prompt-outcome.spec.ts`，验证混合策略牌桌的席位选择和实际保存结果。测试使用本地实验数据，不启动模型采集。
