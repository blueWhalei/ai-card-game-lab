# 第五批 G：研究内训练任务概览

延续已授权 R3、R4、R5、R9、R10，复用第五批 F 的研究侧面板及现有训练页。采用现有 Ink Lab 按钮、分隔列表、分页和折叠说明，不增加调度系统或设计另一套训练界面。

## 验收范围

- 研究侧面板统一为「任务与已记录用量」，切换对局/训练后从第一页读取；对局用量仍只统计调用记录，不混入训练任务。
- 训练归属仅依据任务显式保存的运行 ID 与该运行的研究归属，不从数据集名称或来源猜测。缺少归属的任务仍在训练页查阅。按任务分页 20 条，全部/活动/异常过滤在分页前执行；未知状态归入异常。
- 复用训练列表 API，以研究、运行、任务 ID 和状态条件联合过滤；在同一只读事务核对研究并读取总数、记录和读取时间。准确打开第一页之外的指定任务；不匹配或已删除时不替换为其他任务。
- 展示保存的模型、训练类型、数据集 ID、所属运行、状态、进度和错误记录。进度仅接受有限的 0–1 数字，缺失/无效明确区分，不按零或 100% 补值。错误原因仅展示保存字段。配置/结果损坏不伪造正常结果。
- 完成状态只表示服务保存了完成记录；进度不是剩余耗时，训练完成不证明策略改进，效果需独立留出数据及预先定义的对照。无费用、预算或完整训练资源用量数据。
- 训练页保留原有显式取消/删除/创建确认；概览只读，不启动训练。研究筛选、页码、指定任务与返回路径使用 URL，桌面恢复白名单同步。迟到响应、范围变化和错误不得显示其他研究的旧列表。
- 修复从运行筛选进入训练页创建任务时遗漏运行归属的问题，创建后继续按原范围刷新。
